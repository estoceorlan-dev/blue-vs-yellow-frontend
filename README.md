# Blue vs Yellow

React + Vite frontend for a one-choice voting demo.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Festoceorlan-dev%2Fblue-vs-yellow-frontend&env=VITE_API_URL)

## Local setup

1. Copy `.env.example` to `.env` and set `VITE_API_URL`.
2. Run `npm install`.
3. Run `npm run dev`.

## Vercel

Import this repository, keep the Vite defaults, and set `VITE_API_URL` to the Render API URL ending in `/api`.
